# Autonomous Networks — TM Forum Framework

## What Are Autonomous Networks?

Autonomous Networks (AN) incorporate a simplified network architecture, autonomous domains, and automated intelligent business/network operations for the closed-loop control of digital business. They aim to deliver:

- **Best-possible user experience**
- **Full lifecycle operations automation/autonomy**
- **Maximum resource utilization**

The concept was pioneered by TM Forum in 2019, targeting networks with intrinsic **self-configuration**, **self-healing**, and **self-optimization** capabilities — collectively termed the "Three-Self Capabilities."

---

## Autonomy Levels (L0–L5)

TM Forum defines six levels of network autonomy, similar to autonomous driving levels:

| Level | Name | Description |
|-------|------|-------------|
| **L0** | Manual Operations | Fully human-driven, no automation |
| **L1** | Assisted Operations | System provides assistance; humans execute all tasks |
| **L2** | Partial Autonomous | System executes some tasks under human supervision; humans make decisions |
| **L3** | Conditional Autonomous | System makes decisions and executes in specific domains; humans oversee and intervene when needed |
| **L4** | Highly Autonomous | System autonomously makes decisions and executes across multiple domains; humans monitor and handle exceptions |
| **L5** | Fully Autonomous | System operates completely autonomously across all domains; no human intervention required |

### Current Industry Status (2025–2026)
- Most CSPs currently operate between **Levels 2 and 3**
- Major telcos (China Mobile, MTN Group, Orange, Telefonica, MasOrange) have achieved or are targeting **Level 4** in specific domains
- Level 4 marks the shift from human-defined automation to **true autonomous decision-making**
- Multiple operators declared and validated Level 4 attainment in late 2025 and early 2026
- **MasOrange** became the first operator in Spain to achieve TM Forum Level 4 certification (2026)

## The Autonomous Networks Project

TM Forum's AN Project provides a blueprint including:
- **Strategy** — Business case and roadmap for autonomy
- **Processes** — Operational workflows for autonomous operations
- **Architecture** — Reference architecture for AN implementation

### Key Deliverables:
1. **AN Reference Architecture** — Integrates with O-RAN interfaces
2. **AN Levels Evaluation Tool (ANLET)** — Assessment framework for autonomy levels
3. **High-Value Scenarios (HVS)** — Priority use cases for AN deployment
4. **Solution Packages** — Reusable patterns for AN implementation
5. **AI-driven Self-Healing Patterns** — Automated fault resolution

### AN Manifesto
31 major CSPs and vendors committed to TM Forum's standards and best practices to speed adoption of Autonomous Networks. Signatories include leading global CSPs and vendor companies.

## Key Capabilities at Each Level

### Level 4 — Highly Autonomous (Current Target)
- Autonomous decision-making within defined domains
- Closed-loop automation without human intervention
- Proactive fault detection and resolution
- AI-driven resource optimization
- Intent-based orchestration across service layers

### Level 5 — Fully Autonomous (Future Vision)
- Complete end-to-end autonomy across all domains
- Cross-domain self-optimization
- Fully autonomous business decisions
- Zero human intervention in operations

## Benefits of Autonomous Networks

| Benefit Area | Impact |
|-------------|--------|
| **Operational efficiency** | Reducing maintenance workload by thousands of person-hours |
| **Resource efficiency** | Conserving energy and reducing related costs |
| **Experience excellence** | Reducing faults and complaints, speeding up rectification |
| **Revenue growth** | Enabling new digital services and monetization |
| **Scalability** | Managing increasing network complexity |

4. **Intent-Based Networking** — Declarative management

7. **Agentic AI** — Autonomous AI agents for decision-making
