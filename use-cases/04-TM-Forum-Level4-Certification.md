# Use Case 04: TM Forum Level 4 Autonomous Network Certification

## Summary

In May 2026, MasOrange became the **first operator in Spain** to achieve TM Forum's Autonomous Network Level 4 certification — deploying a network capable of **anticipating failures to safeguard customer experience** in the face of any anomaly.

---

## Certification Process (ANLET)

TM Forum uses the **Autonomous Network Levels Evaluation Tool (ANLET)** to assess and certify operators:

```
┌─────────────────────────────────────────────────────────────────┐
│                    ANLET Certification Process                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. SCOPE DEFINITION                                             │
│     │  Define the network domain(s) being assessed               │
│     │  (e.g., RAN, Transport, Core, Service Assurance)           │
│     ▼                                                            │
│  2. CAPABILITY ASSESSMENT                                        │
│     │  Evaluate against AN Level criteria:                       │
│     │  • Awareness (sensing & data collection)                   │
│     │  • Analysis (AI/ML processing)                             │
│     │  • Decision (autonomous decision-making)                   │
│     │  • Execution (automated action)                            │
│     │  • Learning (continuous improvement)                       │
│     ▼                                                            │
│  3. EVIDENCE VALIDATION                                          │
│     │  Demonstrate capabilities in production environment        │
│     │  Show measurable outcomes and KPIs                         │
│     ▼                                                            │
│  4. CERTIFICATION                                                │
│     │  TM Forum validates and awards level certification         │
│     ▼                                                            │
│  5. CONTINUOUS IMPROVEMENT                                       │
│        Roadmap to next level                                     │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## MasOrange's Path to Level 4

### Building Blocks That Enabled Certification

| Component | Contribution to L4 |
|-----------|-------------------|
| **EIAP + rApps** (Ericsson) | Self-optimization and anomaly detection in RAN |
| **GraphML AIOps** (Google/NetAI) | Deterministic root cause analysis |
| **AI-Centric Transmission** | Self-healing and predictive operations in transport |
| **Unified 5G SA Core** (Ericsson) | Consolidated, cloud-native core architecture |
| **O-RAN Architecture** | Multi-vendor flexibility and openness |
| **5G Advanced** | Advanced radio capabilities across 40 cities |

### Key Differentiator
MasOrange's certification specifically highlights the ability to **anticipate failures** — not just react to them. This proactive capability is what distinguishes Level 4 from Level 3.

## What MasOrange Demonstrated

Based on the certification requirements and MasOrange's known deployments:

### Domain: Network Assurance & Fault Management
```
BEFORE (Level 2-3):
  Alarm → Human reviews → Human diagnoses → Human fixes → Verify

AFTER (Level 4):
  Anomaly predicted → AI diagnoses root cause → Automated fix →
  Auto-verify → Learn → Improve prediction
```

### Domain: RAN Optimization
```
BEFORE (Level 2-3):
  KPI degradation → Alert → Engineer analyzes → Manual parameter change

AFTER (Level 4):
  Continuous monitoring → AI detects pattern → rApp decides optimal
  config → Automated change → Verify improvement → Learn
```

### Domain: Energy Management
```
BEFORE (Level 2-3):
  Static energy policies → Manual schedule adjustments

AFTER (Level 4):
  Real-time traffic analysis → Dynamic energy policy → Automated
  feature activation/deactivation → Zero service impact guaranteed
```
